# WARP ENGINE

## HOW TO BUILD
Install latest Vulkan SDK (also add GLM and Vulkan Memory Allocator headers in it)
Run CMakeLists.txt in root directory - all should work from there on?

### DEPENDENCIES

- Vulkan SDK (with GLM and VMA)
- Slang (currently not a fully integrated part of Vulkan SDK)
- cgltf (https://github.com/jkuhlmann/cgltf)
